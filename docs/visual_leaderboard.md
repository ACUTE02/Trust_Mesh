# Visual Engine Leaderboard (Version 1)

Frozen CLIP ViT-L/14 embeddings + a small head. **Fake is the positive class.** Every cell is ROC-AUC with a 95% stratified bootstrap CI (1,000 resamples, first seed), or "not yet run". Generated by `scripts/build_visual_leaderboard.py` -- do not edit by hand.

Each fold holds one generator family out of training entirely (leave-one-family-out). "T1 known" is that fold's test on generators it trained on; "T3 unseen" is its test on the held-out family. Folds share training data, so they are shown one by one and never pooled into a single CI.
